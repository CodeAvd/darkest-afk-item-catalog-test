## Usage in Catalog

These items appear in two places:

1. **Featured Items Section** (top of `index.html`) - Visual showcase with images
2. **Main Item Grid** - Searchable and filterable with all other items

## Localization

The catalog supports toggling between English and Russian names using the "Show Russian labels" checkbox in the header controls.
